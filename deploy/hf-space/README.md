# Signal — live demo

A thesis-driven dealflow sourcing + diligence agent for early-stage crypto / AI companies.
This Space runs the **offline demo**: bundled fixtures + the deterministic heuristic scorer, no API
keys. Press **Run**, open a ranked company, and generate its source-cited memo.

Source, docs and the always-on static dashboard: https://github.com/YAlegend/signal
